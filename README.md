# P30 Agent Financial OS

`Agent Financial OS` 是一个面向智能体（Agent）的金融操作系统项目，目标是把“策略、风控、执行、审计、复盘”串成可编排、可观测、可扩展的统一平台。

## 项目定位

- 面向多智能体协作的金融操作系统底座
- 支持从信号到执行的全链路自动化
- 强化风控、审计与合规可追溯能力

## 核心工作流

1. 数据接入与标准化
2. 策略生成与评估
3. 风险检查与资金约束
4. 交易执行与状态回报
5. 事后审计与策略复盘

## 核心模块

- 数据层（市场数据、账户数据、事件流）
- 策略层（规则策略、模型策略、Agent协作）
- 风控层（仓位、敞口、止损、异常检测）
- 执行层（订单路由、交易适配器、重试机制）
- 审计层（日志、决策链、绩效归因）
